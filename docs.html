RMCLib Documentation

How RMCLib works

RMCLib is a fully static, YAML-driven guitar chord and lyrics website. There is no server, no database, and no build step — just HTML, CSS, and vanilla JavaScript that reads a single songs.yaml file to power the entire library.

Project Structure

All site files live in a single flat directory:

rmclib/
├── index.html ← Main page (hero, song cards, detail panel)
├── docs.html ← This documentation page
├── css/
│  └── style.css ← All styles (dark theme, responsive, lightbox)
├── js/
│  └── app.js ← YAML parser, cards, filters, audio, lightbox
├── data/
│  └── songs.yaml ← ⭐ All song data lives here
├── images/
│  └── *.jpg / *.png ← Cover art (referenced in songs.yaml)
└── audio/
   └── *.mp3 ← Demo audio files (referenced in songs.yaml)

Running Locally

Because songs.yaml is loaded via fetch(), browsers block requests over the file:// protocol. You must serve the site through a local HTTP server.

Python (built-in, recommended)

# Python 3 python3 -m http.server 8080 # Then open: http://localhost:8080

Node.js

npx serve .
ℹ Any HTTP server works. The site has no backend dependencies whatsoever.

YAML Format

YAML was chosen over JSON for readability — it's far easier to write and edit multi-line lyrics, chord lists, and prose without escaping quotes or worrying about trailing commas.

The file at data/songs.yaml contains a single top-level key songs whose value is a list of song objects.

# data/songs.yaml
songs:
- id: my-song
 artist: Artist Name
 genre: Rock
 difficulty: Beginner
 key: G
 bpm: 120
 title: My Song Title
 description: A short sentence shown on the card.
 coverImage: images/my-song.jpg
 sections: - ...
✓ Comments start with #. Use them freely to organise the file.

Song Fields

FieldTypeDescription
idstringUnique slug. Use lowercase with hyphens, e.g. hotel-california.
titlestringFull song title displayed on the card and detail panel.
artiststringArtist or band name shown above the title.
genrestringGenre label. Used to generate filter buttons automatically.
difficultystringBeginner, Intermediate, or Advanced. Controls the badge colour.
keystringMusical key, e.g. G, Em, Bm.
bpmnumberTempo in beats per minute. Shown in the metadata strip.
descriptionstringTwo-line max description shown on the card preview.
coverImagestringRelative path to the cover image, e.g. images/cover.jpg. Optional — a key-letter placeholder shows if omitted.
sectionslistOrdered list of content sections displayed in the detail panel.

Adding a Song

01
Open data/songs.yaml Add a new - item under the songs: key with the fields listed above.
02
Drop your files into place Put cover images in images/ and audio demos in audio/. File names must match what you wrote in the YAML.
03
Refresh the browser The new card appears in the grid instantly. No build step, no restart.
⚠ YAML is indentation-sensitive. Use 2-space indents consistently. Tabs are not allowed.

Section Types

Each song's sections list can contain any combination of the five types below, in any order, repeated as many times as needed.

TypePurposeRequired fields
textPlain prose paragraph — about the song, technique notes, history.heading, content
chordsChord names displayed with syntax highlighting. Chord tokens (e.g. G, Am) are auto-highlighted.heading, content
lyricsLyrics with inline chord markers. Wrap chords in square brackets: [G]heading, content
audioCustom audio player with progress bar. Supports any number per song.heading, src
imageInline image with skeleton loading, hover zoom hint, and click-to-lightbox.heading, src

Section: text

Use for any prose content — song history, technique descriptions, strumming patterns written out in plain text.

- type: text
 heading: About This Song
 content: >
  Written in 1968, this song was inspired by J.S. Bach's Bourrée in E minor.   The fingerpicking pattern...
ℹ The > block scalar folds newlines into spaces, producing a single paragraph. Use | to preserve line breaks.

Section: chords

Lists chords with automatic syntax highlighting. Any standard chord name (G, Am, F#m, Dsus4, C/E) is wrapped in a gold badge automatically.

- type: chords
 heading: Chords Used
 content: | G | D | Em | C All open chords in the key of G.
 No capo required.

Section: lyrics

Lyrics with inline chord markers. Wrap chord names in square brackets immediately before the syllable they fall on. Line breaks are preserved.

- type: lyrics
 heading: Verse 1
 content: |  [G]Blackbird singing in the [Am]dead of night
 [G/B]Take these [C]broken wings and learn to [D]fly
✓ Use the | literal block scalar so each line is preserved exactly. You can add blank lines between sections.

Section: audio

Renders a custom audio player with a play/pause button, progress bar, and elapsed/total time. You can add multiple audio sections per song.

- type: audio
 heading: "Demo Track – Verse"
 description: Strummed arrangement at 87 BPM.
 src: audio/my-song-verse.mp3

Place .mp3 files in the audio/ folder. If a file is missing, the player shows a warning notice instead of breaking.

⚠ Only one audio track plays at a time. Opening a new track auto-pauses the previous one.

Section: image

Displays an image inside the detail panel. Images load progressively with a shimmer skeleton and open in a fullscreen lightbox when clicked.

- type: image
 heading: Chord Diagram
 caption: Finger position for the F#m barre chord. # optional
 src: images/fsharp-minor-diagram.png

Image Optimisation

Card images use an IntersectionObserver to defer loading until each card scrolls into the viewport (with a 200 px lookahead margin). This prevents the page from fetching images that the user may never scroll to, which eliminates the stuttering caused by many large images loading simultaneously on page load.

While an image is loading, a shimmer skeleton animation fills the placeholder. Once the image loads, it fades in smoothly and the skeleton fades out. If loading fails, a key-letter placeholder is shown instead.

✓ For best results, export cover images at 800 × 450 px (16:9) and save as JPEG at 80% quality. This keeps file sizes under 100 KB while maintaining visual quality.

Lightbox & Zoom

Any image section can be clicked to open a fullscreen lightbox. The lightbox:

  • Shows a shimmer skeleton while the full-size image loads
  • Fades the image in once loaded
  • Allows mild zoom on hover (further in-place zoom)
  • Closes on backdrop click, close button, or Escape key
  • Displays an optional caption from the section's heading field
ℹ The lightbox overlays the detail panel, not the entire page, so the panel scroll position is preserved when the lightbox is closed.

Filters

Filter buttons are generated automatically by scanning all unique genre and difficulty values in songs.yaml. You never need to edit any HTML or JavaScript to add a new filter — just add a new genre or difficulty to a song entry and the button appears.

Audio Player

The audio player is fully custom-built. Features include:

  • Clickable progress bar for seeking
  • Elapsed / total time display
  • Auto-stop of previous track when a new one starts
  • Graceful warning if the audio file is missing
  • All players stop when the detail panel is closed

Deployment

Upload the entire project folder to any static host. No server-side processing is needed.

GitHub Pages

# Push to a GitHub repo, then enable Pages in Settings → Pages
git init
git add .
git commit -m "Initial RMCLib site"
git remote add origin https://github.com/you/rmclib.git
git push -u origin main

Netlify (drag & drop)

Drag the project folder onto app.netlify.com. Done.

Vercel

npx vercel
ℹ All static hosts (GitHub Pages, Netlify, Vercel, Cloudflare Pages, any web server) work with no configuration. There is nothing to compile or build.

Custom Logo

The header and footer currently use an inline SVG guitar icon. To replace it with your own logo image:

01
Place your logo file Save it as images/logo.png (or .svg). Recommended size: 72 × 72 px, transparent background.
02
Replace the SVG block in index.html and docs.html Find every <svg class="logo-img-svg"> block and replace it with:
<img class="logo-img" src="images/logo.png" alt="RMCLib logo">
03
That's it The .logo-img CSS class already sizes and aligns it correctly.
